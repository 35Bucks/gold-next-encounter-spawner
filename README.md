# Gold Next Encounter Spawner v1.1.4

This is **v1.1.1 unchanged in behavior**, with one addition only: the physical **X key acts as BACK/CANCEL**.

Nothing else from v1.1.1 was changed: the SPAWNER menu still uses Gen1Recomp's native menu, so arrow navigation remains exactly as in v1.1.1.

## X key

- SPAWNER menu: **X** closes the menu.
- Pokemon name / Dex entry: **X** cancels the naming screen and goes back.
- Level picker: **X** cancels the level picker.

Existing controls remain unchanged.

## Install

In Gen1Recomp: **MODS -> Import mod .zip**.

## v1.1.4
- Fixed only one issue: on the first use after launching, the Space key used to confirm the Pokemon name could carry into the level picker and instantly accept the default level.
