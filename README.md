 Gold Next Encounter Spawner

A lightweight Pokémon Gold mod for **Gen1Recomp** that allows you to choose which Pokémon will appear in your next wild encounter — including its level.

Designed to integrate directly into the game without permanently modifying normal encounter behavior.

## Features

- Spawn any Pokémon available in Pokémon Gold
- Search/select Pokémon by name or Pokédex number
- Choose the exact encounter level
- Force only the next wild encounter
- Optional REPEAT mode for continuous encounters
- Cancel a pending spawn at any time
- Integrated SPAWNER menu
- Keyboard/controller-friendly navigation
- Normal encounters automatically resume after a one-time spawn
- No ROM included

## How It Works

Open the in-game menu and select:

`SPAWNER`

From there you can:

### SET POKEMON

Choose the Pokémon you want to encounter by entering its name or Pokédex number.

Examples:

`LUGIA`

`CELEBI`

`PIKACHU`

After confirming the Pokémon, choose the desired level.

The selected Pokémon will replace your next normal wild encounter.

### SELECT LEVEL

After choosing a Pokémon, select its level.

Controls:

- UP / DOWN — Change level by 1
- LEFT / RIGHT — Change level by 10
- A / SPACE — Confirm
- X — Back / Cancel

### REPEAT MODE

`REPEAT: OFF`

The selected Pokémon appears once. After the encounter, wild encounters automatically return to normal.

`REPEAT: ON`

The selected Pokémon and level will continue appearing in normal wild encounters until the pending spawn is cancelled.

### CANCEL PENDING

Immediately removes the currently selected forced encounter and restores normal wild encounters.

## Installation

1. Download the latest release `.zip`.
2. Open the Gen1Recomp launcher.
3. Go to `MODS`.
4. Select `Import mod .zip`.
5. Choose the downloaded ZIP.
6. Enable **Gold Next Encounter Spawner**.
7. Launch Pokémon Gold.

Do not enable multiple versions of the mod at the same time.

## Usage

Example:

1. Open `START`
2. Select `SPAWNER`
3. Select `SET POKEMON`
4. Enter `LUGIA`
5. Confirm the name
6. Select `LEVEL 40`
7. Confirm
8. Walk into an area with normal wild encounters
9. Your next encounter will be Lugia Lv.40

With REPEAT disabled, encounters return to normal immediately afterward.

## Controls

### Spawner Menu

- UP / DOWN — Navigate
- A / SPACE — Select
- X — Back / Exit

### Pokémon Name Selection

Use the Pokémon Gold naming interface to enter the Pokémon name or Pokédex number.

- A / SPACE — Select / Confirm
- X — Back / Cancel

### Level Selection

- UP / DOWN — ±1 level
- LEFT / RIGHT — ±10 levels
- A / SPACE — Confirm
- X — Back / Cancel

## Compatibility

Designed for:

- Pokémon Gold
- Gen1Recomp

This mod targets normal wild encounters.

Certain special encounter systems may behave differently because they do not necessarily use the standard wild encounter flow.
